# Documentation

Guides for the OpenAPI code generators. Package READMEs give a short quick
start. These pages cover the full configuration.

Only OpenAPI 3.0 documents are supported.

## Getting started

- [C#](./getting-started/csharp.md): MVC server base classes, `HttpClient`
  extension methods, webhook clients and models, generated during the build by a
  source generator.
- [TypeScript](./getting-started/typescript.md): a framework-agnostic client
  generated by a CLI (from npm or as a .NET tool), with adapters for fetch,
  RxJS and MSW.

## Reference

- [C# MSBuild items and metadata](./reference/csharp-msbuild.md): the csproj
  items, their metadata, and how namespaces are chosen.
- [C# options and schema extensions](./reference/csharp-options.md): the
  options YAML file and the `x-` extensions read from OpenAPI documents.
- [TypeScript CLI and options](./reference/typescript-cli.md): command-line
  arguments and the options YAML file.
